# CuraLink
**CuraLink, an E Hospital Record Management System**

**OverView ->>**
_Curalink is a fully functional E-Hospital Management System developed using the MERN stack (MongoDB, Express.js, React.js, Node.js). This application is designed to streamline and manage all aspects of a hospital's operations, providing comprehensive features for administrators, doctors, and patients.
_

**Features ->>**
**Admin Panel->>**

User Management: Manage all users including doctors and patients.
Appointment Management: Schedule and oversee appointments across the hospital.
Hospital Resources: Track and manage hospital resources such as rooms, equipment, and inventory.
Reports & Analytics: Generate and review reports on hospital operations and performance.

**Doctors Panel->>**

Patient Management: Access and manage patient records, medical histories, and prescriptions.
Appointment Management: View and manage their own appointment schedules.
Consultation Notes: Add and review notes from patient consultations.
Medical History Tracking: Keep track of patients' medical histories and previous consultations.

**Patient Panel->>**

Profile Management: Manage personal information and medical history.
Appointment Booking: Book appointments with available doctors.
Medical Records: Access and review personal medical records.
Prescription Management: View prescriptions provided by doctors.


**Technology Stack->>**
Frontend: React.js
Backend: Node.js, Express.js
Database: MongoDB
Cloud Storage: Cloudinary (for storing and managing images and other media)
API Testing: Postman (for API development and testing)
Authentication: JWT (JSON Web Tokens) for secure authentication






**Installation->>**
**Clone the repository:**

Clone the repository:
git clone https://github.com/SHADOW78548/Curalink.git


Navigate to the project directory:->>
cd Curalink


Install dependencies for both frontend and backend:
cd frontend
npm install
cd ../backend
npm install
Set up environment variables:

Create a .env file in the root of the backend directory.
Add the necessary environment variables such as database URI, Cloudinary credentials, and JWT secret.


Run the application:

Backend:
cd backend
npm run dev


Frontend:
cd frontend
npm run dev


Access the application:
Visit http://localhost:4000 in your browser.
